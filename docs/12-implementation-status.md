### 2026-11-16 — Domain-neutral AI page breadth and larger generation budgets

The full-page designer no longer frames the configured model as a Christian-ministry-only designer or constrains composition guidance to a small page-type recipe list. Any legitimate public page described in the staff brief may be planned and composed. The default balanced depth now directs 5-10 purposeful sections rather than accepting the habitual three-section result; concise and detailed modes guide 3-6 and 7-12 sections, while explicit single-section requests remain valid. Planning output capacity increased from 2,500 to as much as 6,000 tokens, full visual section generation from 5,000 to as much as 12,000, native-object revision to as much as 10,000, and canvas-section revision from 4,500 to as much as 12,000. The main brief now accepts 12,000 characters, with proportionally larger goal, audience, visual-direction, required-content, constraint and confirmed-fact fields. Each output budget adapts downward to the configured model's advertised output ceiling and rejects models below the stage minimum instead of sending an invalid provider request. The validated canvas composition is bounded at 650 KB and editor preview/save/scoped-revision input at 750 KB. Browser-driven stage advancement now allows 30 authenticated calls per minute so a twelve-section page can complete without contradicting its own route throttle. The proposal status reports the actual section count instead of subtracting two legacy sections. PHP, frontend, provider, browser, accessibility and real-model quality gates remain to be rerun after this change.

### 2026-11-14 — Section-based AI design canvas

Generation now explicitly composes at 1440px, 768px, and 390px, rejects narrow desktop strips and repetitive text-only sections, and reserves readable line lengths for inner containers rather than shrinking section roots. CSS is no longer optional: compatibility probe version 7 and runtime validation reject empty, trivial, or non-responsive CSS. Focused canvas/probe tests pass with 8 tests and 16 assertions; Blade compilation and the production Vite build pass.

The AI page designer no longer asks models to construct registered elements, field/value arrays, column weights, responsive setting arrays, or the native page composition contract. Public and editor previews use an opaque-origin sandbox, explicit theme-token messaging, bounded automatic height, and user-activated top navigation. AI JavaScript is disabled for this release.
